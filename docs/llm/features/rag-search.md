# rag-search.md — P-06 RAG 검색

질문 → 근거 검색(Chroma) → Claude 답변 + 출처. 별도 화면 없이 **홈 대시보드의 질문창**에 있다(`home.html`, API `POST /api/rag/ask`).
코드: Spring `service/rag/RagService`(집계 덧붙이기·출처를 원문으로), AI `ai/app/rag/`(`period` 기간 해석, `answer` 검색·근거 판정·답변), 프롬프트 `ai/prompts/rag/answer.md`.

## 결정 사항 (2026-10-21 사용자)

- **LangChain은 쓰지 않는다.** 정의서에는 LangChain으로 되어 있지만, 검색 한 번·답변 한 번이라 Anthropic SDK를 바로 부른다(정형화와 같은 방식).
- 모델은 정형화와 같은 `claude-sonnet-5`(`claude.model`).
- 범위는 질문·답변·출처까지. **답변 만족도 평가는 P-08 때** 만든다. 질문·답변을 저장하지 않는다(화면을 닫으면 사라진다).
- 기준 유사도는 점수 분포를 보고 임시로 정한다 → 아래 0.60.
- **"요즘"은 기간으로 자르지 않고 최신성 가중치로 최근 자료를 앞세운다**(2026-10-22 사용자 결정, 반감기 4주). 처음엔 최근 4주로 잘랐는데, 데이터가 띄엄띄엄이면 관련 깊은 5주 전 자료를 버리고 덜 관련된 1건으로 답하게 되어 바꿨다.
- **별도 화면을 만들지 않고 홈에 둔다**(security-monitoring 홈처럼 요약 카드 아래 질문창·답변 박스). 정의서 화면 구성의 "홈 — 간단 질문창"에 맞춘 것이다. 잠깐 등록됐던 프로그램 `rag-search`는 기동 때 `DataInitializer`가 지운다.

## 근거 판정

- 유사도 = 1 − 코사인 거리(0~1). 질문과 비슷한 청크를 `rag.top-k`(기본 8)개 찾아, **`rag.min-score`(기본 0.60) 이상인 청크만** 근거로 쓴다.
- 근거가 하나도 없으면 **Claude를 부르지 않고** "근거 자료 없음"으로 답한다(`NO_EVIDENCE`). 토큰도 쓰지 않는다.
- 근거가 있어도 질문에 맞지 않으면 Claude가 `grounded=false`로 답하고, 화면에는 "근거 자료 없음 — (부족한 점)"이 나온다(`MODEL_DECLINED`).
- 인용 번호가 없는 답, 인용한 문서가 모두 삭제·재분석 중인 답(`SOURCE_MISSING`)은 내보내지 않는다. 출처 없는 답을 만들지 않기 위해서다.
- **0.60은 임시값**이다(2026-10-21, 이미지 32건·질문 16개로 잼). 관련 질문의 1위 근거는 0.64~0.78이었다. 데이터에 없는 패션 주제(수영복·가방·운동화·웨딩·가죽 재킷)는 0.48~0.59, 패션과 무관한 질문은 0.29~0.37이었다. 텍스트 자료가 쌓이면 AI 서비스 `GET /search?q=`로 분포를 다시 재서 고친다. 운동화(0.58)처럼 기준 바로 아래인 주제가 있어 너무 낮추면 엉뚱한 근거가 붙는다.

## 기간

- **기간이 없는 질문**("요즘"·"최근" 포함): 게시일로 자르지 않는다. 유사도로 후보 30개를 모으고, 기준 유사도(0.60) 이상만 남긴 뒤 **유사도 × 0.5^(경과일/28)**로 다시 순위를 매겨 상위 `rag.top-k`개를 근거로 쓴다. 번호도 이 순위다.
  - 예: 이번 주 유사도 0.70 → 0.70, 8주 전 유사도 0.80 → 0.20. 관련 있는 최근 자료가 앞선다. 관련 없는 최신 자료는 기준 유사도에서 걸러진다.
  - 최근 관련 자료가 없으면 오래된 자료가 그대로 올라온다(따로 넓히는 단계가 없다). 가장 최근 근거도 **8주가 넘으면 stale**로 표시하고, Claude에게 자료 시점을 밝히게 하며, 화면 답 위에 노란 안내를 띄운다.
  - 화면에는 근거로 쓴 원문의 게시일 범위("근거 게시일 10/20 ~ 10/22, 최근 자료 우선")를 늘 보여 준다.
- **기간을 콕 집은 질문**: 그 게시일 범위로 자른다(`app/rag/period.py`). 지난주·이번 주·지난달·이번 달·최근 N일/주/개월·올해·작년은 그 기간, 시즌 표현(올가을·26FW 등)은 그 시즌 기사가 몇 달 앞서 나오므로 최근 6개월. 범위 안에 근거가 없으면 근거 없음(그 기간을 같이 알림). "전월 대비"는 비교 표현이라 기간으로 보지 않는다.
- 기준일은 Spring 서버 날짜(`today`)다. 게시일은 원문 게시일, 없으면 업로드일(집계 날짜와 같다).
- Chroma는 문자열 범위 비교를 못 해서 청크 메타에 게시일 숫자 `published_num`(20261022)을 둔다(기간을 콕 집은 질문의 필터용). 그 전에 색인한 청크는 AI 서비스가 기동할 때 메타만 채운다(다시 임베딩하지 않는다).
- **AI 서비스와 날짜는 문자열(`"2026-10-22"`)로 주고받는다.** `AiClient`의 RestClient 기본 JSON 설정은 `LocalDate`를 `[2026,10,22]` 배열로 써서 AI 서비스가 422로 거부했다(2026-10-22). 가짜 AiClient를 쓰는 API 테스트로는 안 드러나므로 실제 직렬화는 `AiClientWireTest`가 본다. 422(요청 형식 오류)면 사유에 필드(`loc`)와 이유가 남는다.
- Claude에게는 오늘 날짜·기간을 `<period>`로 주고, 근거마다 게시일(`date`)을 붙인다. 오래된 자료와 최근 자료가 다르면 최근 것을 앞에 쓴다.

## 규칙

- 근거는 **문서 단위로 묶어** 번호를 붙인다. 같은 문서의 청크가 [1]·[2]로 갈리지 않고, 출처 칩 하나가 문서 하나다.
- 주간 집계는 **근거가 아니라 참고 수치**다. 집계가 있는 가장 최근 주의 키워드·아이템·소재·컬러·실루엣 상위 5개(전체 카테고리)를 같이 보낸다. Claude는 수치에 인용 번호를 붙이지 않고 기준 주를 같이 말한다. 그 주가 진행 중인 이번 주일 수 있다.
- 이미지 근거는 사진을 분석한 요약 문장이다. 답변에서도 "사진에서 보인다"로 쓰게 한다.
- 질문은 500자까지다(Spring·AI 둘 다 막는다). 답변은 화면에 글자로만 넣는다(HTML로 해석하지 않는다).
- 홈은 프로그램이 아니므로 API는 **로그인만** 요구한다(`@RequiresProgram` 없음). 업로드 화면 권한이 없는 사용자도 요약·출처는 본다.
- 출처의 원문 링크는 원문 문서의 URL이다. 이미지 원본은 이미지 업로드 권한이 있어야 열린다.
- **답의 모양은 스키마로 정한다**(2026-10-22 가독성 개선): 결론 한 줄(`summary` → `answer`) + 글머리 줄 2~5개(`points`, 줄마다 근거 번호). 한 덩어리 글에 [1][2]가 섞여 읽기 어렵던 것을 나눴다. 문장 안에 번호를 쓰지 않게 하고(`rag-answer.md`), 화면이 줄 끝에 번호 단추를 붙인다. 집계 수치만으로 쓴 줄은 번호가 없다. 삭제·재분석 중이라 빠진 출처의 번호는 줄에서도 지운다(`RagService.points`).
- 홈은 마지막 답 하나만 보여 준다. 출처는 번호 순 목록(제목 링크 · 매체 · 날짜 · 유형, 근거 청크 첫 줄)이고, 줄 끝 번호를 누르면 그 출처로 가서 잠깐 강조한다.

## 비용·속도

- 근거 8건 답변 한 번에 입력 약 2,400·출력 약 500토큰, 10초 안팎이다(2026-10-21 실측). 질문 임베딩은 CPU에서 1~2초 걸린다.
- 토큰은 Spring 로그(`RAG 질문 … 토큰`)와 AI 로그(`RAG 답변 …`)에 남는다.
