# rag-search.md — P-06 RAG 검색

질문 → 해석 → (유행 질문) 집계 + 예시 원문 / (그 밖) 근거 검색 → Claude 답변 + 출처. 별도 화면 없이 **홈 대시보드의 질문창**에 있다(`home.html`, API `POST /api/rag/ask`).
코드: Spring `service/rag/`(`RagService` 흐름, `QuestionInterpreter` 규칙 해석·기간, `TrendFactsService` 유행 집계), AI `ai/app/rag/`(`interpret` 질문 해석, `answer` 검색·답변), 프롬프트 `ai/prompts/rag/interpret.md`·`answer.md`.

## 결정 사항 (2026-10-21~22 사용자)

- **LangChain은 쓰지 않는다.** 검색·답변 몇 번이라 Anthropic SDK를 바로 부른다(정형화와 같은 방식). 답변 모델은 `claude.model`(`claude-sonnet-5`).
- 범위는 질문·답변·출처까지. **답변 만족도 평가는 P-08 때.** 질문·답변을 저장하지 않는다.
- **별도 화면 없이 홈에 둔다**(security-monitoring 홈처럼 요약 카드 아래 질문창). 잠깐 등록됐던 프로그램 `rag-search`는 기동 때 `DataInitializer`가 지운다.
- **유행 = 많은 사람이 입어 대중화된 것.** 그래서 **유행 질문은 개수(원문 수·매체 수)로 답한다** — 문장이 비슷한 자료 몇 건으로 "유행"이라고 하지 않는다. 처음엔 문장 유사도로 답했는데, 요약 문구에 "아우터 트렌드로 보인다"가 들어간 후드·패딩이 뽑히고 많이 올린 데님 재킷은 기준 유사도 아래로 빠졌다.
- **질문 해석은 AI(작은 모델)가 한다**(A안). 규칙은 미리 넣은 말만 알아들어서다. 해석 호출이 실패하면 규칙으로 대신한다(답변이 멈추지 않게). 도구 호출(tool use)로 Claude가 스스로 집계·검색을 고르는 B안은 복합 질문에 낫지만 시간·비용이 들쭉날쭉하고 집계를 건너뛸 위험이 있어 보류했다.
- 기간이 없는 **검색** 질문("요즘" 포함)은 자르지 않고 최신성 가중치(반감기 4주)로 최근 자료를 앞세운다. 기간이 없는 **유행** 질문은 최근 4주를 센다.

## 질문 해석

- **AI 해석**(`/interpret`, `claude.interpret-model` 기본 `claude-haiku-5-5`, effort low): 질문 → {유행 질문인지, 카테고리, 아이템 종류, 기간}. 카테고리·종류는 **공통코드 enum**에서만 고르고(카테고리 이름 옆에 속성의 일상 표현을 힌트로 준다), 종류를 골랐으면 그 종류의 카테고리를 따른다. 기간은 날짜가 바르고 from ≤ to ≤ 오늘일 때만 쓴다. Spring은 공통코드에 없는 값을 버린다.
- **규칙 해석**(대체, `QuestionInterpreter`): 유행 단어 = 공통코드 `RAG_TREND_WORD` 코드명, 카테고리 = `TREND_CATEGORY` 이름·속성(재킷·바지…), 종류 = `TREND_ITEM` 이름과 괄호 안 표기(긴 이름이 이김, 기타 종류는 제외). 기간 규칙: 지난주·이번 주·지난달·이번 달·최근 N일/주/개월·올해·작년, 시즌 표현(올가을·26FW)은 최근 6개월. "전월 대비"는 비교 표현이라 기간이 아니다.
- 화면 질문 줄 아래에 해석 결과("유행 질문 — 원문 수로 판단 · 아우터 · AI 해석")를 보여 준다. "규칙 해석"이 보이면 AI 해석이 실패한 것이다(로그 `질문 해석(AI) 실패`).
- 실측(2026-10-22): 해석 한 번 1~2초(첫 호출 4.5초), 입력 약 1,860·출력 50~200토큰. "요새 사람들 겉옷 뭐 많이 입어?"(유행·아우터), "블루종 어떻게 코디해?"(검색·블루종) 같은 말을 알아들었다.

## 유행 질문 — 집계로 답한다

- **센다**(`TrendFactsService`, 질문할 때 바로 — 주간 배치를 기다리지 않는다): 분석 완료 원문 중 기간 안·범위(카테고리·종류) 안의 것을, 아이템 종류·카테고리(범위가 없을 때)·소재·컬러·실루엣별로 **원문 수**(한 원문에 여러 번 나와도 1)와 **매체 수**(서로 다른 출처), 직전 같은 길이 기간의 원문 수로 센다. 축마다 상위 5개.
- **매체 수**: 대중화는 여러 곳에서 보이는 것이다. 한 매체가 같은 옷을 여러 번 올린 것과 가르기 위해 같이 센다. 같은 원문이 다시 들어온 것은 저장 단계에서 URL로 막는다([`document-upload.md`](document-upload.md)). 수기 업로드는 모두 "직접 업로드" 한 매체라, Claude가 "한 매체 자료라 대중화 여부는 더 봐야 한다"고 밝힌다.
- **기간**: 질문이 정한 기간, 없으면 오늘까지 4주. 그 안에 원문이 없으면 범위 원문 중 가장 최근 게시일까지 4주로 옮기고(8주 넘게 오래됐으면 stale — 노란 안내), 기간을 정한 질문은 옮기지 않고 근거 없음.
- **예시 원문**: 첫 축(아이템 종류, 없으면 카테고리) 상위 3개 값마다 최근 원문 2건(종류를 콕 집었으면 그 종류 최근 원문 6건). AI 서비스가 Chroma에서 doc_id로 꺼내 출처로 쓴다(유사도 없음 — 화면 "집계 예시").
- 기간 안에 범위 원문이 없으면 **AI를 부르지 않고** 근거 없음("○○(기간)에 아우터 원문이 없습니다").
- Claude 규칙(`answer.md`): 유행 판단은 집계 개수로만, summary에 1위를 개수와 함께, 개수가 고만고만하면 단정하지 않는다. 화면은 답 아래에 **판단 근거 상자**(범위·기간·원문 수·매체 수, 첫 축 막대, 나머지 축 한 줄)를 그린다.
- 아이템 종류가 없는 예전 분석 결과는 종류 집계에 안 잡힌다 — 재분석해야 한다.

## 검색 질문 — 근거 검색

- 유사도 = 1 − 코사인 거리. **`rag.min-score`(기본 0.60) 이상인 청크만** 근거. 없으면 Claude를 부르지 않는다(`NO_EVIDENCE`). 근거가 질문에 맞지 않으면 `MODEL_DECLINED`.
- 카테고리를 말했으면 그 카테고리 아이템이 있는 원문만 찾는다(청크 메타 `cat_<코드>: True` — Chroma는 목록·부분 일치 필터가 없다).
- 기간이 없으면 후보 30개 → 기준 이상만 → **유사도 × 0.5^(경과일/28)**로 다시 순위 → 상위 `rag.top-k`(8). 가장 최근 근거도 8주가 넘으면 stale. 기간을 정했으면 그 게시일 범위로 자른다(메타 `published_num` 20261022).
- 주간 집계 상위 값(공통코드 `TREND_VALUE_TYPE` 중 속성 RAG인 유형)을 **참고 수치**로 같이 보낸다.
- **0.60은 임시값**(2026-10-21, 이미지 32건·질문 16개): 관련 질문 1위 근거 0.64~0.78, 데이터에 없는 패션 주제 0.48~0.59, 무관한 질문 0.29~0.37. 텍스트가 쌓이면 AI `GET /search?q=`로 다시 잰다.
- 예전 청크의 메타(`published_num`·`cat_*`, `meta_v` 2)는 AI 서비스 기동 때 채운다(다시 임베딩하지 않는다).

## 규칙

- 근거는 **문서 단위로 묶어** 번호를 붙인다(출처 하나 = 문서 하나). 답은 결론 한 줄 + 글머리 줄 2~5개(줄마다 근거 번호) — 스키마로 정한다. 삭제·재분석 중이라 빠진 출처의 번호는 줄에서도 지운다. 출처가 하나도 안 남으면 `SOURCE_MISSING`.
- 이미지 근거는 사진 분석 요약이다("사진에서 보인다"). 질문은 500자까지. 답변은 글자로만 넣는다(HTML 해석 안 함).
- API는 **로그인만** 요구한다(홈은 프로그램이 아니다).
- **출처 열기**: 링크가 있는 원문은 새 탭, **이미지만 있는 원문**은 오른쪽 슬라이드 패널(사진 + 근거 청크 전체). 패널 사진 `GET /api/rag/sources/{docId}/image`는 로그인만 필요하고 **분석이 끝난 이미지 원문만** 열린다.
- **AI 서비스와 날짜는 문자열(`"2026-10-22"`)로 주고받는다.** RestClient 기본 JSON은 `LocalDate`를 배열로 써서 422가 났다(2026-10-22). 실제 직렬화는 `AiClientWireTest`가 본다. 422면 사유에 필드(`loc`)가 남는다.

## 비용·속도

- 검색 답변: 근거 8건에 입력 약 2,400·출력 약 500토큰, 10초 안팎(2026-10-21). 유행 답변: 예시 4건·집계 5줄에 입력 약 3,400·출력 약 630토큰, 7초 안팎(2026-10-22). 여기에 해석 1~2초가 붙는다.
- 토큰은 Spring 로그(`질문 해석(AI)`, `RAG 질문`·`RAG 유행 질문 … 토큰`)와 AI 로그(`질문 해석`, `RAG 답변 mode=`)에 남는다.
